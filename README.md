I enjoy taking systems apart, understanding how they work, and building tools around real problems. My projects range from Linux desktop/software work and developer utilities to data processing, web tooling and experimental research.

## Philosophy

I prefer **evidence over assumptions, source code over marketing and reproducible results over claims**.

Open source is not just a license model for me; it is a way of learning:

1. Find the source.
2. Read the implementation.
3. Reproduce the behavior.
4. Test the assumptions.
5. Improve the result.
6. Share what was learned.
